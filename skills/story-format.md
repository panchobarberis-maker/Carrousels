# Skill: Instagram Story Format — The Lange Firm

Generates a single vertical image (1080x1920, 9:16) for Instagram Stories.

## Key specs

- Size: 1080x1920 px
- Top padding: **240px** — Instagram's header (profile name + close button) covers ~200px at the top
- Bottom padding: 100px — Instagram's reply bar covers the bottom
- Format: JPG quality 95

## Brand

- Colors: navy `#1B2B4A`, gold `#C9A84C`, bronze `#9B6820`
- Fonts: Cormorant Garamond (titles/logo) + DM Sans (body)
- Logo: THE LANGE FIRM (always centered at top, below safe zone)
- Phone: +1 (713) 979-9276
- Tagline: Employment Lawyer in Houston, TX
- CTA: "Contact Us for a Consultation"
- Evan photo: evan.jpeg from Carrousels repo

## Output

Files saved to `EVAN LANGE/stories/<slug>/story.jpg`

## Backgrounds

Same 5 background PNGs from Carrousels repo as carousels.
Pick a different one from the carousel being paired with the story.

## Story types made so far

- **story-hours** — Office hours Mon–Fri 9am–5pm + phone + CTA
  - File: `EVAN LANGE/stories/story-hours/story-hours.jpg`

## Notes

- NEVER use "Free Consultation"
- NEVER use "federal" or law names
- Always Texas context
- Evan photo: center 15%/cover (shows face well)
